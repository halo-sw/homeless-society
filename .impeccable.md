# Design assumptions

Audience: anxious first-time Korean home buyer in an unfamiliar neighborhood. Tone: calm, candid, practical. Warm-paper field notebook plus cartographic workbench; forest-green route accents; deep ink type; fine rules; compact masthead; three-stage progress; one primary action per screen. Korean-friendly stack (Pretendard, Noto Sans KR, system fallbacks); no remote fonts required. Modest hand-authored SVG icons (house glyph favicon); no property photos. Map/schematic fills the workspace; mobile stacks map then notebook. Motion only for selection/state change; honor `prefers-reduced-motion`.
