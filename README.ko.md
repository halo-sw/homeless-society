# Homeless Society 짧은 안내

> 첫 집 마련을 준비하는 분을 위한 오픈소스 가상 임장 노트입니다. 집을 비교하는 세입자에게도 유용합니다.

이 문서는 짧은 입구이며, 기준 문서는 [README.md](README.md)입니다. 자세한 순서와 버튼 이름은 [상세 이용 안내](docs/GETTING_STARTED.ko.md)에 있습니다.

[English](README.en.md)

## 이게 무엇인가요?

실제 방문 전에 준비→가상 임장→정리·비교 흐름을 연습하는 브라우저 앱입니다. 관심사를 고르고 집 두 곳을 관찰한 뒤, 방문 체크리스트와 다시 볼 기록을 남깁니다. 가입 없이 가상 예시로 먼저 체험할 수 있으며, 처음 데모에는 API 키나 설정 파일이 필요 없습니다.

사기 판별, 안전 보장, 중개 대행, 가격 예측은 하지 않습니다. 선택을 대신하지 않고, 무엇을 더 확인할지 정리하도록 돕습니다.

## 어디서 시작할까요?

첫 집 준비가 목적이라면 기준 문서에서 전체 흐름을 읽고, 가상 예시로 두 집을 비교해 보세요. 세입자나 동행자도 같은 흐름으로 관찰과 질문을 나눌 수 있습니다. 여유가 되면 내 주소로 살펴보기와 기록 저장 방법을 읽어보세요.

1. [README.md](README.md)에서 목적과 흐름을 읽습니다.
2. [상세 이용 안내](docs/GETTING_STARTED.ko.md)를 따라 가상 예시를 열어봅니다.
3. 여유가 되면 내 주소와 기록 저장 방법을 읽어봅니다.

소스: https://github.com/halo-sw/homeless-society
