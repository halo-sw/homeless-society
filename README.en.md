# Homeless Society — English README pointer

The canonical English documentation is [README.md](README.md).

Homeless Society is an open-source interactive home-visit and life-scenario notebook for preparing to buy a home in South Korea. It helps you ask better questions, retain dated evidence, and compare two fictional homes. It does not detect fraud.

Start locally:

```sh
npm ci
npm run dev
```

Korean readers can start with [README.ko.md](README.ko.md) and [docs/GETTING_STARTED.ko.md](docs/GETTING_STARTED.ko.md).
