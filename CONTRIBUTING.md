# Contributing

Small, calm PRs. Korean-first UI strings; keep tone candid and practical. No safety/fraud/value/crime/investment claims. No `dangerouslySetInnerHTML`; render user text as text. Keep the three-screen scope; do not add simulators, catalogues, feeds or forecasts.

Checks: `npm install`, `npm test`, `npm run build`. Add Vitest coverage for new domain rules; add Playwright steps for new user flows.

Secrets: never commit `.env`, ledgers, logs or credentials. AI work must stay server-side on `muse-spark-1.3` with budget caps intact.
