# AGENTS

Code in this repo is written by Muse only (model `muse-spark-1.3`). Other agents may orchestrate, review, install and test, but must not author product code or claim authorship.

Constraints: no other model or provider; no copying proprietary sources; no shell execution of user input; no credentials in output, logs or repo; keep budget caps, allowlists and evidence-ID validation; respect the three-screen scope (Prepare, Explore, Compare).

UI condition: the user explicitly requested English UI and a public install-free web deployment. English strings win over older Korean-first assumptions. Translate every visible string to English. Migrate legacy Korean priority values to canonical English (`Commute`, `Groceries`, `Evening walk`, `Building access`) on import; never translate free-text user notes, addresses, or nicknames except known built-in demo defaults (Sunlit House, Moonlight House, Solan Village).
