# Data sources and limits

DEMO: fictional Solanmaeul neighborhood, two homes, synthetic evidence, original SVG schematic. Always labelled hypothetical; schematic is not real geography and implies no walking time.

LIVE: user-provided address/evidence plus Kakao provider data when keys exist. Roadview dates unknown stay unknown; Kakao attribution stays visible; no imagery is downloaded or auto-sent to Muse. Without keys: manual official-map confirmation, coordinates unverified, incomplete-coverage view.

Muse: `muse-spark-1.3` at `https://api.meta.ai/v1` or local `MUSE_BIN` CLI login. Output is question-only JSON with cited evidence IDs, filtered against an allowlist (no safety/fraud/value/crime/investment/mortgage/legal claims). Keyless state stays usable as local template, labelled accordingly.

Known gaps surface as on-site actions (night noise, interior condition). Viewing an item never verifies it.
