# 처음 사용하기

5분 안내입니다. 가상 예시로만 따라 하세요. 실제 주소와 금액을 입력하지 마세요.

## 1. 실행하기

```sh
git clone https://github.com/halo-sw/homeless-society.git
cd homeless-society
npm ci
npm run dev
```

`http://localhost:5173`을 여세요. 키 없이 가상 장면이 바로 나옵니다.

## 2. 준비하기

1. 일상 우선순위를 최대 3개 고릅니다.
2. 궁금한 첫 질문을 1~3개 적습니다.
3. `마포구`를 검색해 `서울특별시 마포구`를 고릅니다.
4. 월과 자산 형태를 고르고 과거 거래를 불러옵니다.
5. 필요하면 12개 요인 가중치나 프리셋을 고릅니다.
6. 첫 화면의 `Enter simulation`을 눌러 바로 시작합니다. 지역 조사는 선택 사항이며 첫 클릭을 막지 않습니다.

거래 표본은 읽기 전용 참고자료입니다. 메모와 섞이지 않습니다.

## 3. 가상 임장하기

1. Sunlit House(햇살집)와 Moonlight House(달빛집)를 바꿔 봅니다.
2. Street(거리), Daily route(일상 동선), Entrance(현관) 정차를 바꿔 봅니다.
3. 시간 슬라이더로 낮과 밤을 봅니다.
4. 공원·학교·카페·마트·역 레이어를 켜고 끕니다.

## 4. 기록 남기기

Field notes(현장 노트) 탭에서 메모, 열린 질문, 출처 URL과 날짜, 분류를 적습니다.

해결 표시, 수정, 삭제, 되돌리기를 쓸 수 있습니다. 집마다 기록이 따로 저장됩니다.

PUBLIC 모드 안내문은 미리 쓴 질문지이며 실시간 AI 답변이 아닙니다.

## 5. 생활 시나리오 해보기

가격·현금, 대출 금리와 기간, 월관리비(Fees) 가정, 편도 통근분과 근무일을 입력합니다.

1~10년 범위와 연 성장 가정을 바꾸며 기준과 금리 +2%p 스트레스를 비교합니다.

기본 월관리비 0.15M원(=15만원) 가정입니다. M은 백만원 단위입니다. 세금·보험·대출 승인은 포함되지 않습니다.

Life scenarios(생활 시나리오)에서 Save scenario snapshot(스냅샷 저장)으로 집마다 저장한 뒤 Go to compare(비교로 이동)로 비교 화면에서 다시 봅니다.

## 6. 비교하고 내보내기

관찰 내용, 빠진 근거, 요인 적용 범위, 지역 표본 출처, 미해결 질문을 확인합니다.

인쇄용 체크리스트와 방문 메모를 쓰고, 필요하면 Save record JSON(기록 저장)으로 내보내고 Import record(가져오기)로 불러옵니다.

200KB 이하만 가져올 수 있으며 주소와 메모가 포함되니 공유 전에 확인하세요.

## 막혔을 때

- 거래가 안 보이면 월·자산을 바꾸고 다시 불러오세요. 아파트 외 자산은 검증에 실패할 수 있습니다.
- 정적 미리보기에서는 실시간 주택 API가 동작하지 않습니다. `npm run dev`나 Vercel 배포를 쓰세요.
- 키보드만으로 이동이 되는지, 390px 모바일에서 넘침이 없는지 확인해 주세요.
